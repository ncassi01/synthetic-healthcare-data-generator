# Synthetic Healthcare Data Viewer

A web-based frontend for viewing and exploring the synthetic healthcare data generated by the data generation pipeline.

## Overview

This web application provides a user-friendly interface to:

- View and explore synthetic member data
- Examine claims, authorizations, and other insurance-related data
- Read clinical notes and care plans
- View communication records
- Visualize data distributions and statistics
- Understand relationships between different data entities

## Setup

### Prerequisites

- Python 3.8 or higher
- All dependencies listed in the main `requirements.txt` file

### Installation

1. Make sure you have generated data using the main data generation pipeline:

```bash
python src/main.py --config config/config.json --output output --process --stats
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the web application:

```bash
python web/app.py
```

4. Open your browser and navigate to `http://localhost:5000`

## Features

### Dashboard

The dashboard provides an overview of the generated data, including:

- Summary counts of members, claims, authorizations, and clinical notes
- Age and gender distribution charts
- Risk score distribution
- Top conditions
- Recent claims and authorizations

### Members

The members page allows you to:

- View a list of all members
- Filter and search for specific members
- View detailed information for a specific member
- See all related data for a member (claims, authorizations, clinical notes, etc.)

### Claims

The claims page displays:

- A list of all claims
- Claim details including service lines
- Financial information
- Claim status

### Authorizations

The authorizations page shows:

- A list of all prior authorizations
- Authorization details
- Authorization status
- Related authorization rationales

### Clinical Notes

The clinical notes page provides:

- A list of all clinical notes
- SOAP-formatted note content
- Provider information
- Related diagnoses and procedures

### Care Plans

The care plans page displays:

- A list of all care plans
- Care plan goals and interventions
- Care plan status
- Target dates and priorities

### Communications

The communications page shows:

- A list of all communication records
- Communication content
- Sender and recipient information
- Communication type and date

### Statistics

The statistics page provides:

- Detailed data distributions
- Demographic breakdowns
- Risk score distributions
- Condition prevalence
- Service utilization patterns

## Architecture

The web application is built using:

- Flask (Python web framework)
- Bootstrap (Frontend framework)
- DataTables (Interactive tables)
- Chart.js (Data visualization)
- jQuery (DOM manipulation and AJAX)

The application reads data from the JSON files generated by the data generation pipeline and serves it through a RESTful API.

## Customization

You can customize the application by:

1. Modifying the templates in the `templates` directory
2. Updating the styles in `static/css/style.css`
3. Adding or modifying JavaScript functionality in `static/js/main.js`
4. Extending the Flask application in `app.py`

## Troubleshooting

If you encounter issues:

1. Make sure you have generated data using the data generation pipeline
2. Check that the data files exist in the expected locations
3. Verify that all dependencies are installed
4. Check the Flask server logs for error messages
